stashsearchjsonford2rmm.zip

This is intended for D2RMM users. I’ve configured it based on the vanilla Stash layout, and you can install it simply by dragging and dropping it into D2RMM’s mod list.
If necessary, you can manually adjust the positions in the JSON file to suit your setup. The reason I haven’t preconfigured or enforced the JSON layout is that I want to respect the layout used by each individual mod.
I could distribute it in MPQ format, but if you’re going to customize it yourself anyway, I personally think it makes more sense to place it directly in the relevant layout folder.
