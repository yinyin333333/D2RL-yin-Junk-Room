you need to insert columns in lvlprest.txt
`File1	File1(N)	File1(H)`
attached TXT file is based on the 3.3casc retail file with added columns.
You can set it by difficulty level, and as you well know, you also need to copy or create a separate JSON file matching the DS1 file name.

If the column content is empty, the existing file1(or whatever difficulty) will be used.
